# 设备电量托盘

Windows 10/11 免安装电量显示工具，针对本机已配对的 Beats Fit Pro 和迈从 A7 V3 Ultra+。双击 `DeviceBatteryTray.exe` 即可运行，无需管理员权限。

## 使用

- 任务栏右下角有两个尽量铺满系统图标区域的电池图形，内部直接显示数字百分比，底部细条也随电量变化。左上绿点代表已连接，灰点代表未连接；耳机使用青色轮廓，鼠标使用金色轮廓。显示 `--` 时设备没有提供可用读数，不代表 0%。Windows 决定通知区域图标的最终尺寸，程序无法单独放大它；若仍觉得太小，可在 Windows 显示设置中提高缩放比例，或使用桌面悬浮窗。
- 鼠标悬停可看设备名称和详细电量。左键点击任一任务栏图标切换桌面覆盖层；右键可立即刷新、设置开机启动、打开电量记录、打开诊断日志或退出。覆盖层仅有耳机、鼠标图形和电量数字，没有背景与标题栏，可拖动到游戏画面角落；在悬浮窗上右键可直接选择“隐藏悬浮窗”，再次点击任务栏图标即可显示。下次运行会恢复其位置与显示状态。独占全屏游戏可能不显示 Windows 桌面覆盖层，使用无边框窗口模式即可显示。
- Windows 可能把新图标放在托盘的 `^` 折叠菜单中。可将两个图标拖到任务栏右下角的可见区域。

迈从鼠标支持当前 USB/2.4G 接收器以及蓝牙低功耗连接。优先使用正在回应的接收器；接收器不可用时查询蓝牙电池服务。接收器已在本机读取到有效回包，电量为 40%。鼠标休眠、未连接或无法读取时不会显示旧电量。

蓝牙广播使用 Windows 原生接口扫描。设备状态未变化时不重复绘制托盘图标和覆盖层，以降低常驻内存及空闲开销。

Beats Fit Pro 的左右耳和充电盒电量需要耳机发送 Apple 蓝牙低功耗广播；通常在佩戴耳机或打开盒盖后才会出现，数值以 10% 为单位。仅在电脑与耳机连接时显示这些数据。覆盖层在获得分项数据时分别显示 `L60% R70%`；没有分项数据时显示 Windows 提供的整体电量，不把整体电量误当作左右耳电量。充电盒电量仅在实际报告时出现在托盘悬停提示和记录中；Windows 也没有可用读数时显示 `--`。目前耳机未连接，分项读取逻辑已通过协议样例测试，仍需在耳机连接时实测。

每次启动程序都会在 `%LOCALAPPDATA%\DeviceBatteryTray` 新建一个带启动时间的 CSV，例如 `battery_history_20261020_153000.csv`；程序运行期间每分钟将两个设备当前状态追加到这个文件，启动后也会立即记一组。每次启动都使用新文件，旧 CSV 永不覆盖、永不删除，关闭程序或关机后仍保留在本机。CSV 含时间、连接状态、整体电量、左右耳与充电盒电量、充电状态和读取来源；空白电量表示没有读数，历史不会用旧值填充。右键菜单中的“打开电量记录”可打开所在目录，CSV 可用 Excel 直接打开或复制导出。设置与诊断日志也保存在同一目录。开机启动默认关闭，开启后只写入当前用户的 Windows 启动项。

## 从源码构建

需要 Windows、Python 3.14 和 PyInstaller。进入源码目录后运行：

```powershell
python -m pip install -r requirements.txt pyinstaller==6.22.0
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

生成的 EXE 在源码目录的 `dist` 子目录。运行测试：`python -m unittest -v test_core.py`。

迈从接收器报文格式参考[迈从电量托盘的 MIT 协议笔记](https://github.com/HifumiDaisuki01/MchoseBatteryTray/blob/main/PROTOCOL.md)和迈从官方网页驱动；Beats 广播格式参考 [AirPodsDesktop](https://github.com/SpriteOvO/AirPodsDesktop) 的公开协议资料。程序不上传设备信息。
